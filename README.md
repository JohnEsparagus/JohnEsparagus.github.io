# Amir Rasul — portfolio

Source for [johnesparagus.github.io](https://johnesparagus.github.io/). Plain HTML and CSS, served by GitHub Pages from the `main` branch.

- `index.html` — projects
- `about.html` — about page
- `style.css` — all styling

To preview locally (optional, needs Ruby):

```
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.
