# setup

1. Replace `me.jpg` with your actual photo (keep the filename, or update `index.html` if you rename it).
2. Edit `index.html` — replace "Your Name" (two spots) and the tagline with your own.
3. Push this whole folder to a repo named `yourusername.github.io`.
4. In repo Settings → Pages, set source to the `main` branch, root folder.
5. Done — live at `https://yourusername.github.io`.

To preview locally (optional, needs Ruby):

```
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.
